FastAPI ML Prediction API

A machine learning prediction API built using FastAPI, Pydantic, Scikit-learn, and Pandas.

The API accepts user information, performs feature engineering such as BMI, lifestyle risk, age group, and city tier calculation, and then uses a trained machine learning pipeline to predict the user's category.

Features
FastAPI REST API
Pydantic input validation
Automatic BMI calculation
Lifestyle risk calculation
Age group classification
City tier classification
Scikit-learn ML pipeline integration
Pickle-based model loading
Swagger UI for API testing
Tech Stack
Python
FastAPI
Pydantic
Pandas
Scikit-learn
Uvicorn
Pickle
